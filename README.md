# PEA Construction & Disbursement Dashboard (PSCTM)

ระบบแดชบอร์ดติดตามสถานะงานก่อสร้างสายส่ง 115 kV, สถานีไฟฟ้า, รายละเอียดการเบิกจ่ายงบประมาณ WBS และการขออนุญาต ของการไฟฟ้าส่วนภูมิภาค (กฟภ. / PEA)

## 🌟 ฟังก์ชันการทำงานหลัก
1. **ภาพรวมโครงการ (Executive Overview)**: สรุป KPI รวม 3 มิติ, กราฟแท่งเปรียบเทียบผลงานความก้าวหน้าโครงการ (%) แบบแสดงชื่อโครงการเต็ม, ตารางงานที่อยู่ระหว่างดำเนินการก่อสร้าง (Active Works)
2. **สถานะงานสายส่ง 115 kV**: ติดตาม 5 โครงการสายส่ง, วงจร-กม. (ทศนิยม 2 ตำแหน่ง), แผน-ผลงานสะสมรายเดือนปี 2568 - 2569, ผลการทดสอบ AC Withstand
3. **สถานะงานสถานีไฟฟ้า**: ข้อมูลภาพรวม 30 สถานี และสถานะงานสถานีไฟฟ้าที่กำลังก่อสร้าง พร้อมรายละเอียดสัญญา ผู้รับจ้าง ผู้ควบคุมงาน และคณะกรรมการตรวจรับฯ
4. **รายละเอียดการเบิกจ่าย (WBS)**: ตารางสรุปการเบิกจ่ายงบประมาณแยกตามรายสถานีไฟฟ้าและยอดรวมทั้งหมด พร้อมระบบ Drill-down ดูรายการย่อย WBS (งบต้นแบบ, งบปัจจุบัน, เบิกจ่ายจริง Act., ภาระผูกพัน PR/PO, งบคงเหลือ)
5. **สถานะการขออนุญาต**: รายการขออนุญาตพื้นที่ (เทศบาล, แขวงทางหลวง, ชลประทาน, เอกชน) พร้อม Filter Pills และช่องค้นหา
6. **แผนงานและผลงาน (Gantt Schedule)**: แผนงานรายสัปดาห์/เดือนของสถานีชั่วคราว น้ำหนักงาน และผลงานคิดเป็น %
7. **Strict Schema Validation Engine**: ตรวจสอบโครงสร้างไฟล์ Excel อย่างเข้มงวด ป้องกันการนำเข้าไฟล์ที่ไม่ถูกต้อง พร้อมแสดงข้อความแจ้งเตือนที่ชัดเจน
8. **ระบบบันทึกสถานะส่วนกลางและการใช้งานร่วมกันหลายเครื่อง (Central Persistence & Multi-Machine Sync)**:
   - บันทึกข้อมูลลงโฟลเดอร์เซิร์ฟเวอร์ส่วนกลาง (`data/latest_data.json` และ `latest_uploaded.xlsx`) อย่างถาวร
   - เพื่อนร่วมงานในเครือข่าย LAN / Wi-Fi สำนักงาน สามารถเปิดเข้าใช้งานพร้อมกันผ่าน IP เช่น `http://172.30.134.151:8080/index.html`
   - เมื่อเครื่องใดก็ตามอัปโหลดไฟล์ ข้อมูลจะอัปเดตเข้าสู่เซิร์ฟเวอร์ทันที และเครื่องอื่นที่เปิดอยู่จะมีแจ้งเตือนอัปเดตแบบเรียลไทม์
   - ปุ่ม **"แชร์ในเครือข่าย"** แสดงที่อยู่ IP พร้อมกดคัดลอกลิงก์ส่งต่อได้ทันที
   - ปุ่ม **"ดาวน์โหลด Excel"** ช่วยให้เพื่อนร่วมงานดาวน์โหลดไฟล์ Excel ล่าสุดที่มีผู้นำเข้าระบบไปใช้งานต่อได้

## 🚀 การเปิดใช้งาน
- **เครื่องเซิร์ฟเวอร์/เครื่องหลัก**: ดับเบิลคลิกไฟล์ `start_dashboard.bat` ระบบจะเปิดเบราว์เซอร์อัตโนมัติ และแสดงที่อยู่ IP ในหน้าต่างคำสั่ง
- **เครื่องเพื่อนร่วมงาน**: เปิดเบราว์เซอร์แล้วพิมพ์ลิงก์ที่แสดงในปุ่ม "แชร์ในเครือข่าย" (เช่น `http://172.30.134.151:8080/index.html`)

## 💻 เทคโนโลยีที่ใช้
- HTML5, Vanilla CSS3 (PEA Purple Design System, Glassmorphism, Dark/Light Mode)
- Vanilla JavaScript (ES6+)
- SheetJS (`xlsx.full.min.js`) สำหรับอ่านไฟล์ Excel ในเบราว์เซอร์
- Chart.js (`chart.umd.min.js`) สำหรับแสดงผลกราฟิก
- Lucide Icons สำหรับไอคอนทันสมัย
- Python HTTP Server ในตัว พร้อม API Storage Persistence และ Real-time Polling
